Armour set bonuses

Four Arms set

Pieces: 4Arms helmet, 4Arms chestplate, 4Arms legging, 4Arms boots

  • Strength II
  • Jump Boost II

Heatblast set

Pieces: Heatblast helmet, Heatblast chestplate, Heatblast leggings, Heatblast boots

  • Fire Resistance I
  • Flight (speed 0.1)
  • No fall damage

Jacket set

Pieces: Jacket

  • Resistance I

Legendary set

Pieces: Knight helmet, Knight Chestplate, Knight leggings, Knight Boots

  • Strength I
  • Resistance II

Plumber set

Pieces: Plumber Helmet, Plumber Chestplate, Plumber Leggings, Plumber Boots

  • Resistance I
  • No fall damage

XLR8 set

Pieces: xlr8 helmet, xlr8 chestplate, xlr8 legging, xlr8 boots

  • Speed III

The set bonus applies while every piece listed for that set is worn.
