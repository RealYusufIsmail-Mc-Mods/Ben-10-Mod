# Alien assets

All alien and Omnitrix art is generated by `tools/alien-gen/`. Never hand-edit the exported PNG/JSON files; change the generator and re-export. Full reference: `docs/assets.md`.

## Add a new alien

1. Read two existing alien functions in `tools/alien-gen/aliens.py` that are close in shape (humanoid: `xlr8`, `ripjaws`; quadruped: `wildmutt`; flying: `stinkfly`; big: `fourarms`).
2. Write `def <id>():` returning a `Model("<id>", 256, 256)`:
   - Use `humanoid_bones(...)` for humanoids, or declare bones with the standard names (`body`, `head`, `right_arm`, ...) so the shared animations work.
   - Build with `m.box` / `m.sym`. Units are pixels, `+Y` up, facing `-Z`. A player is 32 tall.
   - Pick materials from `engine.py`. Mark glowing parts with `glow(...)` or emissive decals.
   - Add the Omnitrix with `chest_omnitrix(m, bone, x, y, z_front)`.
3. Add it to `ALIENS` at the bottom of `aliens.py`.
4. `python3 tools/alien-gen/preview.py <id>` and look at `tools/alien-gen/out/<id>.png`. Iterate until it reads as the character from the front at a glance: silhouette first, then face, then colour.
5. `python3 tools/alien-gen/export.py` to write geo, animation, texture, glow mask and the dial icon.
6. Add `common/src/main/resources/data/bentenmod/aliens/<id>.json` (hitbox, abilities, starter flag, duration; see `docs/data-aliens-and-abilities.md`) and the id to the list in `GameTestChecks.aliensLoaded`. Run both `runGameTestServer` tasks.

## Change an existing alien

Edit its function, preview it, export it. If a material change is global (e.g. AO strength, texel density `D`), re-export everything and preview the whole sheet (`preview.py` with no arguments).

## Check before calling it done

- The preview looks right from the front 3/4 view, and the face reads.
- `export.py` printed the alien with `glow=True` if it has emissive parts.
- Texture size in `geo/alien/<id>.geo.json` matches the PNG (export guarantees this; say so if you hand-edit anything).
- In-game appearance is unverified until someone runs the client. Say that plainly.
