Roadmap

These entries come from the release plan. They are planned work, not features in the current game.

Planned, not in the game yet. Release names and scope may change; the source roadmap does not promise dates beyond version 2.0.0.

Smarter prisoners, Null Guardians, Lepidopterrans, prison blocks with the warden, wrecked Plumber outposts, Taydenite caves, useful drops. Heatblast/Stinkfly/Ghostfreak flight animations.
